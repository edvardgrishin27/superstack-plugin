## Фаза 7 — ЧТО ПЕРЕЖИВЁТ ПРОГОН

Спека умирает в день сдачи. То, что должно её пережить, уходит отсюда.

```bash
python3 "$CLAUDE_PLUGIN_ROOT/tools/memory_file.py" set . --section "Команды" --body "<проверенные>"
python3 "$CLAUDE_PLUGIN_ROOT/tools/memory_file.py" check .
```

Файл памяти пишется **только между маркерами** — всё, что написал человек,
неприкосновенно. Путь, которого нет в репозитории, делает файл красным.

На ярусе **T2 и выше** — архитектурные решения. Только те, у которых был
отвергнутый вариант, и каждое называет зону, которой правит:

```bash
python3 "$CLAUDE_PLUGIN_ROOT/tools/adr.py" new docs/adr "<решение>" --zone src/bot/ --serves R01 \
  --context "..." --decision "..." --because "..." \
  --rejected "<что рассмотрели и чем оно не подошло>" --consequences "..."
python3 "$CLAUDE_PLUGIN_ROOT/tools/adr.py" check docs/adr --tier T2 --manifest .superstack/manifest.json --root .
```

Каждая находка сборки (`D##`) обязана дожить до решения: это дорога, уже
пройденная и найденная закрытой.

Документы прогона связаны между собой, и связность держит скрипт, а не память:

```bash
python3 "$CLAUDE_PLUGIN_ROOT/tools/artifact_graph.py" .superstack
```

Ловит циклы, ссылки в никуда и спеку без тестов.

### Урок на всегда

После сдачи задай себе один вопрос, один раз за прогон: есть ли урок на всегда.
Он не стоит отдельного хода: ты задаёшь его сам, пока прогон не закрыт.
Планка строгая, нужны все три условия: пройденная проверка (тест, прогон,
наблюдаемый эффект, не «мне кажется»), названный паттерн отказа (что именно
ломалось) и хотя бы один отброшенный тупик (что пробовали и не сработало).

```bash
python3 "$CLAUDE_PLUGIN_ROOT/tools/learn.py" add --title "..." --check "..." --failure "..." --deadend "..."
```

Все три есть — запиши. Не все три — НЕ ЗАПИСЫВАЙ и не говори об этом человеку:
чаще всего верный ответ именно такой, а шумную память перестают читать.
Человеку этот вопрос не задаётся.
