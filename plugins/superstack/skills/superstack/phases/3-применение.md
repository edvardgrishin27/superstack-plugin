### Фаза 3 — ПРИМЕНЕНИЕ (обратимо, по одному)

Порядок обязателен:

1. **Сначала бэкап.** Скопируй `~/.claude/settings.json` и `~/.claude.json`
   в `~/.claude/backups/superstack-<метка времени>/`. Путь напечатай **до** правок.
2. **Секреты не копируются в бэкап.** Если находка `sec.secret-in-settings`
   сработала — в копии на месте значения должна остаться метка, а не сам секрет.
   Иначе «критическая починка» превратит одну копию пароля в две.
3. Находки класса `BLOCK` — останавливайся и спрашивай. Никогда не применяй сам.
4. Находки класса `GATE` — покажи в плане, применяй после подтверждения.
5. Находки класса `AUTO` — можно применить, но всё равно назови вслух.
6. **Удаление запрещено.** Всё, что убирается, переносится в карантин
   (`~/.claude/skills-library/` для скиллов) и возвращается одной командой.
7. После каждой правки **перечитай файл и убедись, что изменение на месте**.
   Галочка ставится по результату повторного чтения, а не по факту вызова команды.

### Фаза 4 — ДОКАЗАТЕЛЬСТВО

Установка не считается успешной, пока не прошёл сквозной прогон. Подсчёт файлов
доказывает, что файл существует. **Работоспособность доказывает только
заблокированная попытка.**

Минимум: собрать крошечный проект, **самому подложить падающий тест**, починить
его, увидеть зелёный. Плюс негативные контроли — попытки, которые обязаны быть
отклонены. Зелёный результат, который система написала себе сама, ничего не стоит.

Ступень установки выставляет **скрипт, а не сообщение об успехе**. Это третий
замок: `absent → applied → proven-local → proven` двигается только пройденной
проверкой, и модель не может объявить ступень словами.

```bash
# Позиционных параметров здесь нет намеренно: движок подставляет
# аргументы слэш-команды в тело скилла, и "$1" стал бы словом из
# просьбы человека.
python3 "$CLAUDE_PLUGIN_ROOT/tools/prove.py" run            # прогон с негативными контролями
python3 "$CLAUDE_PLUGIN_ROOT/tools/state.py" show           # какая ступень достигнута
```

Код возврата `prove.py` и есть ответ. Ступень `proven` без него — это «агент
сказал», то есть ровно то, против чего написан весь установщик.
