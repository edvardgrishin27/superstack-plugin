# FIX — звено, а не вина

«Что-то сломалось» — это симптом, а не диагноз. Не гадай причину по памяти
разговора и не показывай человеку стектрейс — он не читается тем, кто не
знает слова «хук».

## Что делать

```bash
python3 "$CLAUDE_PLUGIN_ROOT/tools/fix.py"
```

Инструмент проверяет звенья ПО ПОРЯДКУ и останавливается на первом
разорванном — дальше он не идёт, потому что чинить есть смысл по одному
звену за раз, а не сваливать в кучу все возможные причины.

## Порядок ответа человеку — всегда один

Бери его из полей вывода, ничего не переставляй местами:

1. **какое звено из скольких** — `broken_index` из `total`
2. **что пробовал** — `tried`
3. **сколько звеньев в порядке** — `ok_count`
4. **ровно одна команда дальше** — `next`

Словарь: «ещё не подключено» — не «ошибка», не «баг», не «сломалось».
Человек не виноват — звено просто не на месте.

## Если всё в порядке

`status` — `ok` значит все звенья исправны. Скажи это одной строкой и
попроси описать симптом словами, а не техническими терминами — дальше
разбираться по тому, что расскажет человек, а не по новой попытке
угадать причину.

## Чего делать нельзя

- Показывать список возможных причин вместо одного звена
- Показывать человеку стектрек или технический вывод инструмента как есть
- Предлагать меню вариантов вместо одной команды
- Говорить «ошибка» или искать, кто виноват — виновато звено, не человек
